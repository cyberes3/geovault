# CalTopo Integration Usage Guide

GeoVault has an integration with [CalTopo](https://caltopo.com) that allows you to import maps and features directly from your account into GeoVault. This integration provides a seamless way to transfer your existing CalTopo data without manual file exports.

Entire maps and individual features can be imported.

Linking your account is a little obtuse since it's an unofficial API but it isn't too complicated. Instructions are available
on your `Settings` > `Import` page.

Your CalTopo authentication details are encrypted on the server.

Linking your account will give GeoVault full write access to your Caltopo account!
